## 🚀 快速开始

1. **设置 API 密钥**：
   ```bash
   export LLM_API_KEY="your-openai-api-key-here"
   ```

2. **运行程序**：
   ```bash
   go run cmd/main.go
   ```

3. **开始对话**：
   ```
   👤 用户: 计算 25 * 4 + 10
   🤖 助手: 计算结果: 25 * 4 + 10 = 110
   ```
