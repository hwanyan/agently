# AI Agent 开发教程

这是一个完整的AI Agent开发教程，使用Go语言从零开始构建一个功能完整的AI智能助手。

## 🎯 项目概述

本项目演示了如何构建一个现代化的AI Agent系统，包含以下核心功能：

- 🤖 **智能对话** - 与大语言模型进行自然语言交互
- 🔧 **工具调用** - Agent可以调用外部工具执行具体任务
- 📊 **计算能力** - 内置计算器工具，支持数学运算
- 🌤️ **信息查询** - 天气查询工具，获取实时信息
- 💬 **对话管理** - 完整的对话历史管理和上下文维护
- ⚙️ **配置管理** - 灵活的配置系统，支持文件和环境变量

## 🚀 快速开始

### 1. 环境准备

确保你的系统已安装：
- Go 1.19 或更高版本
- Git

### 2. 获取代码

```bash
# 如果你还没有这个项目，可以创建目录
mkdir ai-agent-tutorial
cd ai-agent-tutorial

# 初始化Go模块
go mod init ai-agent-tutorial
```

### 3. 配置API密钥

有两种方式配置OpenAI API密钥：

**方式一：环境变量（推荐）**
```bash
export LLM_API_KEY="your-openai-api-key-here"
export LLM_MODEL="gpt-3.5-turbo"  # 可选，默认为gpt-3.5-turbo
```

**方式二：配置文件**
编辑 `config.json` 文件：
```json
{
  "llm": {
    "provider": "openai",
    "api_key": "your-openai-api-key-here",
    "model": "gpt-3.5-turbo",
    "base_url": ""
  },
  "agent": {
    "name": "智能助手",
    "description": "一个能够使用工具的智能AI助手",
    "max_tokens": 4096,
    "temperature": 0.7
  }
}
```

### 4. 运行程序

```bash
# 运行主程序
go run cmd/main.go

# 或者运行示例程序
go run examples/basic_example.go
```

## 📚 核心概念详解

### 1. Agent架构

AI Agent采用了经典的"感知-思考-行动"循环：

```go
type Agent interface {
    ProcessMessage(ctx context.Context, userMessage string) (string, error)
    AddTool(tool Tool)
    GetConversationHistory() []Message
}
```

**核心流程：**
1. **接收用户输入** - 获取用户的问题或指令
2. **分析和理解** - 使用LLM理解用户意图
3. **决策** - 判断是否需要使用工具
4. **执行工具** - 如果需要，调用相应的工具
5. **生成响应** - 基于工具结果生成最终回答

### 2. 工具系统

工具是Agent扩展能力的核心机制：

```go
type Tool interface {
    Name() string
    Description() string
    Parameters() map[string]interface{}
    Execute(ctx context.Context, args map[string]interface{}) (string, error)
}
```

**工具特点：**
- **标准化接口** - 所有工具实现统一接口
- **参数验证** - 支持JSON Schema参数定义
- **错误处理** - 完善的错误处理机制
- **可扩展性** - 易于添加新工具

### 3. LLM集成

支持多种大语言模型：

```go
type LLMClient interface {
    Chat(ctx context.Context, messages []Message, tools []Tool) (*Message, error)
    ChatStream(ctx context.Context, messages []Message, tools []Tool) (<-chan string, error)
}
```

**特性：**
- **流式响应** - 支持实时流式输出
- **工具调用** - 自动处理工具调用协议
- **上下文管理** - 维护完整的对话历史

## 🛠️ 开发指南

### 添加新工具

1. **创建工具结构体**：
```go
type MyTool struct {
    name        string
    description string
}
```

2. **实现Tool接口**：
```go
func (t *MyTool) Name() string { return t.name }
func (t *MyTool) Description() string { return t.description }
func (t *MyTool) Parameters() map[string]interface{} { /* 参数定义 */ }
func (t *MyTool) Execute(ctx context.Context, args map[string]interface{}) (string, error) {
    // 工具逻辑实现
}
```

3. **注册工具**：
```go
myTool := NewMyTool()
agent.AddTool(myTool)
```

### 扩展LLM支持

1. **实现LLMClient接口**：
```go
type MyLLMClient struct {
    // 客户端配置
}

func (c *MyLLMClient) Chat(ctx context.Context, messages []Message, tools []Tool) (*Message, error) {
    // 实现聊天逻辑
}
```

2. **集成到Agent**：
```go
llmClient := NewMyLLMClient(config)
agent := agent.NewBasicAgent("助手", "描述", llmClient, systemPrompt)
```

### Q: 如何获取OpenAI API密钥？
A: 访问 https://platform.openai.com/api-keys 注册并创建API密钥。

### Q: 如何添加更多工具？
A: 实现Tool接口并使用agent.AddTool()方法添加即可。

### Q: 程序运行出错怎么办？
A: 检查API密钥配置，确保网络连接正常，查看错误日志获取详细信息。
