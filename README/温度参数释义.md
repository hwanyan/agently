# AI 模型温度参数详解

**温度参数（Temperature）** 是大语言模型中一个非常重要的控制参数，用于调节模型输出的随机性和创造性。

## 温度参数的作用

### **控制输出的随机性**
- **数值范围**：通常在 0.0 到 2.0 之间
- **默认值**：一般为 1.0

### **不同温度值的效果**

#### **低温度（0.0 - 0.3）**
```json
{
  "temperature": 0.1
}
```
- **特点**：输出更加确定性、一致性
- **行为**：模型倾向于选择概率最高的词汇
- **适用场景**：
  - 代码生成
  - 数学计算
  - 事实性问答
  - 翻译任务

#### **中等温度（0.4 - 0.8）**
```json
{
  "temperature": 0.7
}
```
- **特点**：平衡创造性和准确性
- **适用场景**：
  - 日常对话
  - 内容总结
  - 问题解答

#### **高温度（0.9 - 2.0）**
```json
{  
  "temperature": 1.5
}
```
- **特点**：输出更加多样化、创造性
- **行为**：模型会选择更多低概率的词汇
- **适用场景**：
  - 创意写作
  - 头脑风暴
  - 故事创作
  - 诗歌生成

## 技术原理

温度参数影响 softmax 函数中的概率分布：

```
P(word_i) = exp(logit_i / temperature) / Σ exp(logit_j / temperature)
```

- **温度 → 0**：概率分布变得尖锐，高概率词占主导
- **温度 → ∞**：概率分布变得平坦，所有词概率趋向相等

## 在代码中的应用

```go
type AgentConfig struct {
    Name        string  `json:"name"`        
    Description string  `json:"description"` 
    MaxTokens   int     `json:"max_tokens"`  
    Temperature float64 `json:"temperature"` // 控制AI输出的创造性
}
```

这个参数可以让您的 AI Agent 根据不同场景调整输出风格：
- **严谨任务**：设置低温度（0.1-0.3）
- **创意任务**：设置高温度（0.8-1.2）

## 实际应用建议

### 任务类型与温度设置

| 任务类型 | 推荐温度 | 说明 |
|---------|----------|------|
| 代码生成 | 0.1-0.2 | 需要精确性，避免语法错误 |
| 数学计算 | 0.0-0.1 | 要求确定性结果 |
| 技术文档 | 0.2-0.4 | 准确但允许一定表达灵活性 |
| 日常对话 | 0.6-0.8 | 自然且有变化 |
| 创意写作 | 0.8-1.2 | 鼓励创新和多样性 |
| 头脑风暴 | 1.0-1.5 | 最大化创意输出 |

### 调优建议

1. **从默认值开始**：先使用 0.7 作为基准
2. **根据效果调整**：
   - 输出太单调 → 增加温度
   - 输出太随机 → 降低温度
3. **任务导向**：根据具体任务需求选择合适范围
4. **A/B 测试**：对比不同温度值的效果

温度参数是控制 AI 输出质量的重要工具，合理使用能显著提升 AI Agent 的表现。
