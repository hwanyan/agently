# AI Agent 使用指南

## 🚀 快速启动

### 1. 设置API密钥

在运行程序之前，你需要设置OpenAI API密钥。有两种方式：

**方式一：环境变量（推荐）**
```bash
export LLM_API_KEY="sk-your-openai-api-key-here"
```

**方式二：修改配置文件**
编辑 `config.json` 文件，将 `your-openai-api-key-here` 替换为你的实际API密钥。

### 2. 运行程序

```bash
# 方式一：直接运行Go代码
go run cmd/main.go

# 方式二：编译后运行
go build -o ai-agent cmd/main.go
./ai-agent

# 方式三：运行示例程序
go run examples/basic_example.go
```

```

这个计算过程是：

### 复杂计算

```
👤 用户: 帮我算一下 (100 + 50) * 2 - 75

🤖 助手: 我来帮你计算这个复杂表达式。

计算结果: (100 + 50) * 2 - 75 = 225

计算步骤：
1. 括号内：100 + 50 = 150

## ⚠️ 注意事项

1. **API密钥**：确保设置了有效的OpenAI API密钥
2. **网络连接**：需要稳定的网络连接访问OpenAI API
3. **API费用**：使用OpenAI API会产生费用，请注意使用量
4. **响应时间**：首次响应可能需要几秒钟时间

## 🐛 常见问题

### 问题1：程序启动失败
```
❌ 加载配置失败: 未找到LLM API密钥
```
**解决方案**：设置环境变量 `LLM_API_KEY` 或修改 `config.json` 文件

### 问题2：API调用失败
```
❌ 处理消息时出错: LLM调用失败: API请求失败，状态码: 401
```
**解决方案**：检查API密钥是否正确，是否有足够的API配额

### 问题3：工具调用失败
```
❌ 处理消息时出错: 处理工具调用失败: 工具执行失败
```
**解决方案**：检查工具参数是否正确，网络连接是否正常
